## ۱. سامانه ورود و ثبت‌نام
- نوع: Use Case
- بازیگرها: بازدیدکننده، کاربر ثبت‌نام‌شده
- use caseها: ثبت‌نام، ورود به حساب، مشاهده صفحه خوش‌آمد، خروج از حساب
- روابط: ثبت‌نام شامل اعتبارسنجی ورودی‌ها و ذخیره در پایگاه داده است؛ ورود شامل بررسی ایمیل و رمز است.

## ۲. دستگاه خودپرداز (ATM)
- نوع: Use Case
- بازیگرها: مشتری، سیستم بانک، تکنسین بانک
- use caseها: مشاهده موجودی، برداشت وجه، واریز وجه، انتقال وجه، تغییر رمز، چاپ رسید، شارژ دستگاه
- روابط: همه‌ی عملیات مشتری شامل احراز هویت هستند؛ چاپ رسید و مسدود شدن کارت به‌صورت extend عمل می‌کنند.

## ۳. فروشگاه آنلاین لوازم خانگی: Use Case
- بازیگرها: مشتری، مدیر فروشگاه، درگاه پرداخت
- مشتری: ثبت‌نام، مشاهده محصولات، جستجو و فیلتر، مشاهده جزئیات محصول، افزودن به سبد خرید، ثبت سفارش، پیگیری سفارش
- مدیر: مدیریت محصولات، مدیریت دسته‌بندی‌ها، مدیریت سفارش‌ها، مشاهده گزارش فروش
- روابط:
  - ثبت سفارش، پیگیری سفارش و همه‌ی کارهای مدیر شامل «ورود به حساب» هستند (include).
  - ثبت سفارش شامل «پرداخت آنلاین» است و درگاه پرداخت به آن متصل است.
  - جستجو و فیلتر، مشاهده محصولات را گسترش می‌دهد (extend).

## ۴. فروشگاه آنلاین لوازم خانگی: Class Diagram
| کلاس | توضیح |
|---|---|
| User | کلاس پایه‌ی کاربران (نام، ایمیل، رمز هش‌شده، نقش) |
| Customer | مشتری؛ از User ارث می‌برد (آدرس، تلفن) |
| Admin | مدیر فروشگاه؛ از User ارث می‌برد |
| Product | محصول (نام، برند، قیمت، موجودی) |
| Category | دسته‌بندی محصولات |
| Cart و CartItem | سبد خرید و آیتم‌های آن |
| Order و OrderItem | سفارش و آیتم‌های آن |
| Payment | پرداخت مربوط به یک سفارش |

روابط اصلی:
- Customer و Admin از User ارث می‌برند (generalization).
- هر Customer یک Cart دارد و چند Order ثبت می‌کند.
- Cart از چند CartItem و Order از چند OrderItem ساخته شده است (composition).
- هر Order یک Payment دارد.
- هر Product به یک Category تعلق دارد و Admin آن را مدیریت می‌کند.
